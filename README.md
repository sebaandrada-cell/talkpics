# TalkPics

Free communication app (AAC) for non-speaking autistic people and their families. Built by a father for his daughter.

- App: https://tinyurl.com/talkpics-app
- Info page: https://tinyurl.com/talkpics-caa
- Languages: Español, Català, English

## Take the code and make your own version

You can copy this project and change it in your own space. Your copy is yours: nothing you do affects this repository, and only the author can change this one.

1. Click **Fork** (top right on GitHub), or **Code → Download ZIP**.
2. The whole app is one file, `TalkPics.html`. Open it in a browser, or publish your copy on GitHub Pages.
3. If you want your change added here, open a **Pull Request** or write to sebaandrada@gmail.com. The author decides what gets merged.
